# 思考情报台 Web Alpha

这是一个私有的判断工作台，不是信息收藏夹。它让用户记录一个真实问题、放进一条会挑战该判断的材料，并留下“部分接受 / 提出反驳 / 拿真实场景验证 / 暂存”之一的回应。

## 数据与访问边界

- 私有 Sites 部署要求 ChatGPT 登录；每一条问题、材料和判断差分都按服务端身份隔离。
- 数据存入 D1。前端不会提交或决定 owner id，API 会拒绝未登录、跨账户、空回应、未知类型和材料/问题不匹配。
- 选择“拿真实场景验证”时必须写明验证场景，状态会保留为 `needs_validation`。
- 判断差分不是 stance；外部材料和 AI 都不能自动改写用户的临时立场。

## 开发与验证

```bash
npm run db:generate
npm test
npm run lint
npm run build
```

`npm test` 覆盖私有访问边界、回应字段校验和跨账户/问题不匹配保护。发布由 Sites 完成，D1 binding 为 `DB`，不使用对象存储。
